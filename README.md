# UPSC Prelims PYQ Dashboard

Interactive static dashboard for UPSC Prelims PYQ analysis, with the 2026 paper mapped against historical PYQs and the master syllabus.

## Run locally

Open `index.html` directly, or serve this folder with any static server.

```powershell
python -m http.server 8765
```

Then open `http://127.0.0.1:8765/`.

## GitHub Pages

Live site: https://rkjat65.github.io/upsc_prelims/

GitHub Pages is configured from the `gh-pages` branch root.
